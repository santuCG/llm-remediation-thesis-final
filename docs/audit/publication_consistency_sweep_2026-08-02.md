# Publication-Level Documentation Consistency Sweep (2026-08-02)

**Scope.** Every markdown file, diagram, README, methodology description, figure, workflow explanation, limitation, contribution, result, and statement in the repository (55 in-scope files; `applications/**`, `tools/*_bin/**` vendored binaries, and `archive/**` content excluded except for a label-accuracy check), checked against the actual final frozen pipeline (`.github/workflows/*.yml`, `scripts/**`) and the frozen evidence (`results/execution_evidence/`, `results/reproducibility_verification/`). Conducted as Phases A-D of the publication-readiness plan approved 2026-08-02.

**Governing rule applied throughout:** every claim was tagged CURRENT-PIPELINE (must match code as it stands now) or HISTORICAL-EVIDENCE (must match what was actually recorded, imperfections disclosed rather than hidden), plus a change-type: Documentation clarification / Documentation correction / Scientific clarification / Historical clarification / Methodology clarification / Editorial improvement. No code, evidence, or methodology was changed at any point in this sweep — every fix below is a documentation change only, consistent with the no-scope-creep constraint.
